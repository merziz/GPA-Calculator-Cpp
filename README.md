# C++ GPA & Grade Calculator

## Overview
This repository contains a C++ application developed as a Semester 1 Programming project (BITP1113). It processes student academic scores to dynamically calculate their GPA, convert the average into fractional representation using Euclidean algorithms, and determine their final degree classification.

## Features & Logic
* **Dynamic Input:** Accepts multiple subject codes and corresponding marks via arrays.
* **Algorithmic Math:** Utilizes Euclid's algorithm to calculate the Greatest Common Divisor (GCD) for accurate decimal-to-fraction conversions.
* **Control Structures:** Implements looping and conditional logic to evaluate GPA thresholds against standard degree classifications (e.g., 1st class, 2nd class upper/lower).

## Technologies
* **Language:** C++
* **Environment:** Microsoft Visual Studio
